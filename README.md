# Mi Petite Boutique

Boceto de cortesía para Isa Quintero. Catálogo + QR de feria. No es tienda con pagos.

Instagram: [@mipetiteboutique_](https://www.instagram.com/mipetiteboutique_/)

## Local

```bash
npm install
npm run dev
```

http://localhost:3021

- `/` ficha y lookbook
- `/catalogo` piezas → pedido por Instagram
- `/qr` para imprimir en el stand

WhatsApp, cuando lo tenga: `NEXT_PUBLIC_WHATSAPP=57…`
